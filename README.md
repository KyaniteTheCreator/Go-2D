# Go 2D

Go 2D is a fun 2D platformer built with Godot. Jump across challenging levels, avoid obstacles, and put your skills to the test as you race to reach the end.

Play the game here:
https://go2d.netlify.app/

Controls
A / Left Arrow - Move Left
D / Right Arrow - Move Right
W / Space - Jump
W / Space (Click x2) - Double Jump
W / Space (Click while walking into a wall) - Wall Jump

Built With
Godot Engine
GDScript
